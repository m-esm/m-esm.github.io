Autonomous delivery sits at the meeting point of two worlds: a partner's digital service and robots moving through the physical world. The platform connects those worlds; the surrounding tools make that connection usable by engineers and operators.

Robotics & making / 2026 · JulyParvizA desk robot, from code to CAD.

A desk robot designed from software to mechanics: tracked drive, a Raspberry Pi touchscreen face, a camera eye, and a pan/tilt neck. Parametric Python generates the assembly; the software spike includes face rendering, motion and camera integration.

The design explores a self-locking worm-drive tilt mechanism, a captured-ball pan race, and positive-drive tracks. The repository documents interference checks, assembly order and cable routing. The mechanical design is not yet printed or assembled.

AI tools / 2026 · AugustSmart subagentsGive each coding task the right worker.

A quota-aware task router for coding CLIs. It considers available headroom, task size and reasoning difficulty, dispatches work in an isolated Git worktree, and verifies the resulting diff before reporting back.

Size and difficulty are separate decisions: a broad rename and a small concurrency fix demand different kinds of work. The public implementation includes worker eligibility, fallback selection, cooldowns and outcome-based routing feedback.

Robotics & making / 2026 · AugustMechlibMechanisms you can generate.

Reusable parametric parts for FDM printing: gears, cams, linkages, ratchets, couplings and flexures. Built with trimesh, Shapely and manifold3d.

An interactive browser gallery combines mechanism animations with editable parameters, running the Python library through Pyodide. Bought-part envelopes are kept separate from printed geometry.

Robotics & making / 2026 · June–JulyCode → CAD → printA connected set of fabrication tools.

Three companion tools turn parametric Python into inspected geometry and sliceable Bambu Studio projects. Imported STEP, IGES and STL files can join the same workflow.

AI tools / 2026 · OctoberJev Model RouterMatch reasoning effort to the prompt.

A Claude Code plugin that uses TypeSafe Jev scores to select model and reasoning effort, with explicit routing rules.

It distinguishes prompt difficulty from continuation, preserves model-scoped cache considerations and applies routing through hooks. This is a separate decision from smart-subagents, which chooses a worker with available quota.

Robotics & making / 2026 · JulyTorque leverA small print that answers a real question.

A printable lever for measuring a door-lock tailpiece’s operating torque with a luggage scale, to inform actuator motor selection.

The primary measurement hole is 102 mm from the axis. For a perpendicular pull, torque is scale mass × 9.81 × lever length: roughly 1 Nm per kilogram at that hole. The second hole is 51 mm from the axis.

Parviz / Robotics

Parviz: a desk robot

A tracked robot designed around a Raspberry Pi 5, a touchscreen face and a camera eye. Parametric Python CAD connects printed parts, a pan/tilt neck and drive tracks. The mechanical assembly is a CAD prototype; the repository also contains a working software spike.

Mechlib: code into parts

A Python library of parametric mechanical components: gears, cams, linkages, ratchets, couplings and flexures. The interactive gallery lets you inspect mechanisms and retune parameters in the browser with Pyodide.

Enlarged source CAD, with a lightweight loading model. Not yet printed or assembled. Click the robot to separate its assemblies.

Smart subagents / AI tools

The right agent for the work

Smart subagents routes coding tasks using CLI quota headroom and task difficulty. Work runs in an isolated Git worktree, with diff verification before reporting back. Task size and reasoning difficulty are treated separately.

One instance per branch

Multi Branch runs an instance for each branch of a Node.js repository and selects between them using an HTTP header. It is an earlier exploration of isolated development environments, a theme that also appears in my agent tooling.

The routing exhibit is a deterministic illustration of the public project. No live agents or account access.
